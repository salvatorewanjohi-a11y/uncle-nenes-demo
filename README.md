# Uncle Nene's Kitchen: online ordering demo

A demo of the Uncle Nene's Kitchen WooCommerce ordering site (Nairobi's best burgers, Ngummo & Garden Estate) that runs entirely in the browser with WordPress Playground.

- Ordering site: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/uncle-nenes-demo/main/blueprint.json
- Store admin (menu, prices, orders, group orders): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/uncle-nenes-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test orders are not kept.
